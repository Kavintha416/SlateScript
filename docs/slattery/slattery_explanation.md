# Slattery(UI)

Slattery is a UI framework extension for SlateScript. It adds native GUI capabilities using the egui library. The extension system allows Slattery to hook into the language without modifying the core parser/interpreter.

- The current slattery is a demo and is still under testing so expect bugs

slattery is designed based on react and html with its own .sts file (which might be removed and turned into .st files with styles) to create styles
